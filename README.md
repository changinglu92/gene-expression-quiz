# 基因的表达 · 快问快答 红蓝 PK

高三一轮复习公开课《基因的表达》课堂竞赛网页：10 道转录、翻译相关判断题和选择题，最后一题接到 TMEM175 与途径 1。

公开地址：https://changinglu92.github.io/gene-expression-quiz/

## 课堂上怎么用

1. 教师用投影电脑打开首页，点击「我是教师，发起 PK」。大屏会出现 4 位房间号和二维码。
2. 学生用手机或平板扫码（没有 iPad 的同学同样可以参加），选择加入红队或蓝队。
3. 教师看到两队人数后，点击开始。每题 20 秒，也可以提前锁定揭晓。
4. 计分看各队正确率（答对人数 ÷ 本队人数，未作答记为不正确），两队人数不等也比较公平。全程结束后比较平均正确率。

## 题目说明

用字一律写作「核苷酸 / 核糖核苷酸 / 脱氧核糖核苷酸」。判断题第 1 题「转录的原料是脱氧核糖核苷酸。」为错误，解析为：转录的原料是核糖核苷酸；脱氧核糖核苷酸是 DNA 复制的原料。

## 课堂网络

学生端作答需要能访问本题站点，并允许访问 `ntfy.sh`（用于把答案同步到教师大屏）。若大屏提示通道连不上，请刷新教师页重试；此时仍可用大屏出题讲评。
