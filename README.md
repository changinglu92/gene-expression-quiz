# 基因的表达 · 快问快答 红蓝 PK

高三一轮复习公开课《基因的表达》课堂竞赛网页：10 道转录、翻译相关判断题和选择题，最后一题接到 TMEM175 与途径 1。

公开地址：https://changinglu92.github.io/gene-expression-quiz/

## 课堂上怎么用

1. 教师用一体机或投影电脑打开首页，点击「我是教师，发起 PK」。大厅会显示 4 位房间号和二维码，方便台下同学加入。
2. 台上请红、蓝各一位同学站到大屏左右两侧。台下同学用手机或平板扫码（也可输入房间号），选择加入红队或蓝队；没有 iPad 的同学同样可以参加。
3. 教师看到人数后，点击屏幕中间的金色大按钮「开始答题」（底栏也有同一个按钮）。
4. 台上规则：左右两侧各自作答，题目不必同步。一位同学点选后，立刻进入自己的下一题，另一位继续做自己正在做的那一题。每题限时约 20 秒，到时未答记为错误并自动进入下一题。先把 10 道题全部答完的一方获胜。竞赛过程中不揭晓、不讲解，避免停下来。
5. 计分分两层：
   - **台上**：看谁率先完赛，并统计各队答对题数与用时。
   - **台下正确率**：座位上的同学在手机上也是一道接一道作答；正确率 = 答对题数 ÷（本队人数 × 10），未作答记为不正确。
6. 双方完赛后（或教师按「结束并讲解」），大屏会列出全部 10 道题，标出红队、蓝队的对错，并默认停在第一道错题。老师可用「上一题 / 下一题 / 下一道错题」对着大屏幕讲评。

## 题目说明

用字一律写作「核苷酸 / 核糖核苷酸 / 脱氧核糖核苷酸」。判断题第 1 题「转录的原料是脱氧核糖核苷酸。」为错误，解析为：转录的原料是核糖核苷酸；脱氧核糖核苷酸是 DNA 复制的原料。

## 课堂网络

学生端作答需要能访问本题站点，并允许访问 `ntfy.sh`（用于把答案同步到教师大屏）。若大屏提示通道连不上，请刷新教师页重试；此时台上作答与讲评仍可在大屏上进行。
