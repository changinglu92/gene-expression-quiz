# 基因的表达 · 快问快答 红蓝 PK

高三一轮复习公开课《基因的表达》课堂竞赛网页：10 道转录、翻译相关判断题和选择题，最后一题接到 TMEM175 与途径 1。

公开地址：https://changinglu92.github.io/gene-expression-quiz/

## 课堂上怎么用

1. 教师用一体机或投影电脑打开首页，点击「我是教师，发起 PK」。大厅会显示 4 位房间号和二维码，方便台下同学加入。
2. 台上请红、蓝各一位同学站到大屏左右两侧。台下同学用手机或平板扫码（也可输入房间号），选择加入红队或蓝队；没有 iPad 的同学同样可以参加。
3. 教师看到人数后，点击「开始本题」。大屏变为三栏：左边红队、中间抢答、右边蓝队，两侧题目相同。
4. 台上规则：选项先可见但不可点。一位同学先按中间的「抢答」，按钮变为「请作答」后，两侧选项都可点选；谁先在本队一侧点出答案，就锁定该队作答，另一侧随即锁定。教师再按「揭晓」判定对错并计分，不自动揭晓。若抢答错误，可按「对方补答」，由另一队在自己一侧作答。「重抢」会取消本题当前的抢答与作答，回到本题开始。节奏一律由教师控制（开始本题 / 揭晓 / 下一题 / 重抢）；倒计时约 20 秒仅作提示，到时不会自动进入下一题。
5. 计分分两层：
   - **台上得分**（主计分，给黑板前两位同学）：抢答正确 +10，抢答错误 0；补答正确 +5，补答错误 0。
   - **台下正确率**（揭晓后公布）：座位上的同学在手机上同步作答，答对人数 ÷ 本队人数，未作答记为不正确。两队人数不等也比较公平。
6. 全部结束后，先公布台上胜负与台上总分，再对照两队的台下正确率。

## 题目说明

用字一律写作「核苷酸 / 核糖核苷酸 / 脱氧核糖核苷酸」。判断题第 1 题「转录的原料是脱氧核糖核苷酸。」为错误，解析为：转录的原料是核糖核苷酸；脱氧核糖核苷酸是 DNA 复制的原料。

## 课堂网络

学生端作答需要能访问本题站点，并允许访问 `ntfy.sh`（用于把答案同步到教师大屏）。若大屏提示通道连不上，请刷新教师页重试；此时台上抢答、出题讲评仍可在大屏上进行。
